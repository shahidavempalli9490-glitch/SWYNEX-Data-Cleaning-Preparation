# Employee Data Cleaning and Preparation

## Project Overview
This project focuses on cleaning and preparing an employee dataset for data analysis as part of **SWYNEX Technologies Task 1**. The main objective is to improve data quality, maintain consistency, and prepare structured employee data for further analysis using Microsoft Excel.

## Tool Used
- Microsoft Excel

## Dataset Information
The dataset contains employee details such as:
- Employee Name
- Age
- Salary
- Gender
- Department
- Position
- Joining Date
- Performance Rating
- Email
- Phone Number

## Data Cleaning Activities
The following data cleaning activities were performed:

- Identified and checked missing values in employee records.
- Checked for duplicate records to avoid repeated data.
- Reviewed and corrected data types where necessary.
- Standardized inconsistent text values, such as department names and gender entries.
- Validated joining dates and numerical values.
- Checked email formats and phone number consistency.
- Prepared the dataset for further analysis.
